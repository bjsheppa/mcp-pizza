# Contributing

## No personal information in this repo

This project is meant to be shared publicly. Never commit:

- Home or delivery addresses, names, emails, phone numbers
- Card data, tokens, API keys, or `.env` files
- Logs (`logs/`), order read-backs, or captured API responses containing customer details
- Scratch notes, scripts, or test output created while using a real address

Use obviously fake data in tests, examples, and docs (e.g. `123 Main St`, `john.doe@example.com`, `5555551234`). Keep real-world notes in a private repo.

Before committing, check `git diff --staged` for anything personal.
